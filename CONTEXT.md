# GitHub Profile

This context defines the language used to present Ivan Reutenko on his public GitHub profile.

## Language

**Profile README**:
The public introduction rendered on Ivan's GitHub profile Overview.
_Avoid_: Repository list, portfolio site

**Professional identity**:
Frontend Architect is Ivan's most recent position title. Tech Lead and Team Lead are earlier position titles in his professional history.
_Avoid_: Claiming that any title is current, presenting all three as simultaneous roles, generic frontend developer

**Professional focus**:
Conceptual challenges in frontend development, especially architecture, developer experience, and scalability.
_Avoid_: Framework-specific implementation work as the primary positioning

**Public activity card**:
The secondary profile element that summarises recent public GitHub activity without ranking or language scoring. It supports the engineering evidence rather than serving as the primary proof of expertise.
_Avoid_: Generated widget, stats dashboard, contribution score

**Profile visual language**:
Modular ledger cards use GitHub-native neutral surfaces, restrained contribution greens, explicit evidence cells, dedicated desktop and mobile compositions, and an automatic dark theme.
_Avoid_: One large poster-style dashboard, decorative gradients, badge walls, desktop cards merely scaled down on mobile
